DWIN Image Sender

Sends a picture from this browser to the STM32 board over USB (Web Serial). The board draws it on the DWIN display through UART1. No SD card needed.

This page needs Chrome or Edge on a computer, because it uses Web Serial. Open the file in one of those browsers.
